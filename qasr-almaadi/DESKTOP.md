# نسخة سطح المكتب (ويندوز) — تعمل بدون إنترنت

برنامج ويندوز حقيقي (Electron) يشغّل نفس السيرفر وقاعدة البيانات المحلية (PGlite) داخل البرنامج نفسه، وتُعرض الواجهة الأصلية بدون أي تعديل. كل البيانات على الجهاز، ولا يحتاج إنترنت ولا سيرفر ولا تثبيت قاعدة بيانات.

## التثبيت
1. نزّل `QasrAlMaadi-Setup-<الإصدار>.exe` من تبويب **Actions** في GitHub (Artifacts) أو من **Releases**.
2. شغّله واختر مكان التثبيت. سيُنشأ اختصار "نظام مستشفى قصر المعادي" على سطح المكتب.
3. عند أول تشغيل تظهر شاشة الإعداد: اسم المستشفى، ويوزر المدير وكلمة مروره (16 حرفًا على الأقل)، وكلمة سر النسخ الاحتياطي (16 حرفًا على الأقل ومختلفة عن كلمة المرور). **احتفظ بكلمة سر النسخ الاحتياطي خارج الجهاز؛ لا يمكن استرجاع أي نسخة بدونها.**

## أين تُحفظ البيانات
`%APPDATA%\QasrAlMaadi\data` للمستخدم الحالي في ويندوز. الإزالة (Uninstall) لا تحذف البيانات.

## النسخ الاحتياطي والاسترجاع
- تلقائيًا: نسخة مشفّرة (AES-256-GCM) كل 24 ساعة عند فتح البرنامج، في `Documents\QasrAlMaadi-Backups`، ويُحتفظ بآخر 14 نسخة. انسخ هذا المجلد دوريًا إلى فلاشة أو جهاز آخر.
- يدويًا: قائمة **النظام ← نسخة احتياطية الآن** (القائمة تظهر بضغط Alt).
- الاسترجاع: **النظام ← استرجاع نسخة احتياطية…** يُنشئ نظامًا جديدًا من النسخة دون حذف الحالي.

## التحديث
ثبّت الـ installer الأحدث فوق القديم؛ البيانات تبقى كما هي. (نظام التحديث الموقّع الخاص بسيرفر Linux غير مفعّل هنا.)

## التطوير والبناء
يتطلب Node.js 24.
```
npm ci
npm run desktop:dev      # تشغيل البرنامج للتجربة
npm run test:desktop     # اختبار الإعداد والدخول وإعادة التشغيل
npm run desktop:dist     # بناء ملف التثبيت (على ويندوز)
```
البناء الرسمي يتم تلقائيًا في GitHub Actions (`.github/workflows/build-windows.yml`).

## متغيرات اختيارية
`QASR_DATA_DIR` (مكان البيانات)، `QASR_PORT` (المنفذ المحلي، الافتراضي 4310).
