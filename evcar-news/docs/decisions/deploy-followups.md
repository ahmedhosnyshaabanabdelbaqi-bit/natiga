# Follow-ups requested by the deployment kit

Open items for backend/admin/mobile/CI owners, raised while building and reviewing `deploy/`.

- [ ] Backend (media/storage, not my area): public /media responses served by Node should send `Access-Control-Allow-Origin: *`. The app's Pannellum WebView loads textures with crossOrigin=anonymous from origin `null`, which the CORS allowlist rejects. The kit covers it in Caddy mode (Caddy serves /media) and in the nginx/Apache vhosts, but not for other setups
- [ ] Backend (config/mail): allow a production state where mail is disabled and reported as 'not configured' in /admin/system/integrations, e.g. MAIL_DRIVER=console or a new `disabled` value. Production currently refuses to start without SMTP, so the kit falls back to a local mailpit outbox, which makes the status page say SMTP is configured
- [ ] Backend (jobs): add a headless worker entry point (e.g. dist/worker.js, or HTTP_ENABLED=false) so the worker container does not open an HTTP port
- [ ] backend/Dockerfile and admin/Dockerfile (not edited): both need a real `docker build` in CI. Also suggested: a CI job that publishes images to GHCR so small VPSes can pull instead of building, and pinning admin's `node:22.22-alpine` / `nginx:1.29-alpine` to exact tags like the backend does
- [ ] CI (.github/workflows/evcar-ci.yml, not my area): add a deploy job running `shellcheck -x deploy/*.sh deploy/lib/*.sh deploy/tests/*.sh`, `docker compose ... config` on an env from `deploy/install.sh --generate-env-only`, `caddy validate`, and deploy/tests/local-e2e.sh (needs postgis + redis service containers; set CADDY_BIN/NGINX_BIN)
- [ ] Share links / website integration: SHARE_BASE_URL stays https://evcar.news (contract default), but the share pages (/n/, /cars/, /compare/, /.well-known/) are served on https://api.evcar.news. Either the website routes those paths to the API, or the admin changes the share base URL to https://api.evcar.news until it does
- [ ] Mobile: the 360° viewer's allowed media origin / navigation delegate must include https://api.evcar.news (media lives at https://api.evcar.news/media)
- [ ] Root README.md and docs/REQUIREMENTS_TRACKER.md (not my area): link docs/DEPLOYMENT.md and docs/DEPLOYMENT_AR.md, and update §19 (scheduled backups, restore test, monitoring/alerts) and §23 (server deployment instructions, Docker settings) to 'done, partially verified — images not built here'
