## InventoryService (row-locked, transactional, idempotent by reference)
`receive(variant, warehouse, location, qty, reference, actor)`, `reserve(variant, warehouse|null (best available), qty, orderItem)` → fails with `inventory.errors.insufficient_stock` when available < qty (never negative), `release(reservation)`, `transfer(item, toLocation, qty)`, `deliver(reservation|item, qty, reference)` (consumes reservation, physical −), `return(...)`, `damage(item, qty, reason)`, `adjust(item, qtyDelta, reason, actor)` (permission inventory.adjust, audit + reason), `availableFor(variant): int`, `recalculate(item)` from the ledger, `inventory:reconcile` command (ledger vs read model per item; opening + receipts + returns + positive adjustments − deliveries − damage − negative adjustments = physical; report Passed/Warnings/Failures; never fixes; raises OperationsExceptions). Update `product_variants.stock_cached` (Catalog read model) through a public method `InventoryService::syncVariantStock($variantId)` guarded by `Schema::hasTable`.

## Pages (admin, permission inventory.*)
`/admin/warehouses` (CRUD + locations tree + printable location labels with BarcodeService), `/admin/inventory` (stock overview DataTable: variant, warehouse, physical/reserved/damaged/quarantine/available, filters, export), item detail with movement ledger (Timeline) and reservations, receive form, transfer, adjustment (reason required), counts workflow (create → count sheet (mobile) → differences → approve → adjustments), packages (create from received shipment items or order, print label QR/Code128, scan page), `/admin/inventory/scan` (mobile-first pages using `QrScanner`: receiving, count, picking (order pick list), packing, "move to event", each with big touch targets and offline-tolerant retry messaging — no native app). Scanning a barcode returns: shipment, order, owner, contents, quantity, location, delivery status (permission-scoped: delivery officers see only what they need). KPIs: `inventory_value` (Σ physical × last landed cost or variant price — document the method), `inventory_reserved`. Health checks: negative read models, items whose ledger doesn't match. Exporters: inventory stock, movements.
