## Rules
- Redemption: partner scans membership QR (MembershipQr::verify with purpose 'offer') → server checks membership active, offer active/dates, eligibility rules (vehicle make/model from member vehicles), usage limits (per member & total, row-locked count) → creates redemption with a short code → partner sees only: valid, member name, member number, offer eligibility. Nothing financial. Second redemption beyond the limit fails with a clear message. Member can also present a redemption code generated in the portal (verification_method code).
- Home charging workflow per contract statuses; member compares quotes in a structured table (equipment, installation, cable allowance, extra meter cost, warranty, date, total); accepting one declines others; appointments/installation/report/warranty recorded; documents private with `HasAttachments` authorization (member + assigned partner + staff).

## Pages
- Public: `/{locale}/offers` (active offers grid, filters category/governorate/vehicle), `/{locale}/offers/{offer}`, `/{locale}/partners/{partner}`, `/{locale}/home-charging` (info + chargers catalog + CTA).
- Member: `/account/offers` (eligible offers per my vehicles, generate redemption code, my redemptions), garage section `offers`, `/account/home-charging` (create request wizard, track status via StepIndicator, quotes comparison + accept, appointments, report & warranty).
- Partner: `/partner/offers` (own offers CRUD if partner user; service centers can also publish offers), `/partner/offers/verify` (QrScanner + code input → result card), `/partner/redemptions`, `/partner/home-charging` (assigned requests: survey, quote form, appointment, installation report).
- Admin: `/admin/partners` (CRUD, approve, branches, users), `/admin/offers` (moderation, eligibility rules, limits, stats), `/admin/home-charging` (requests board, assign partners, chargers catalog). KPIs `offers_active`, `home_charging_open_requests`. Audience `partner_customers` optional.
