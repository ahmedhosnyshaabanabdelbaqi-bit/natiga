## Rules
- Provenance everywhere: every status/tariff shows source + timestamp; "Available now" only when `status_source = live_api` and `last_status_at` within `charging.live_freshness_minutes` (default 15); older → "last known status (time)" or unknown. Community reports are displayed as "community report" with time, never as official status; N consistent reports within 48h flag the station for verification (`charging.reports_threshold`). Unknown tariff shows "price unknown" (never "free").
- Freshness: stations with `last_verified_at` older than `charging.freshness_days` (default 90) get `needs_verification` badge; admin verification dashboard lists: needing verification, stale data, conflicting reports (reports disagreeing with current status), missing tariffs, duplicate candidates (same name/within 100 m).
- Compatibility for the member's vehicle uses `MemberVehicle::compatibleStationConnectorTypeIds()` → direct / via adapter / incompatible badges per station; never assume from vehicle name.
- Search: governorate, area, distance radius (5/10/25/50 km/custom — straight-line haversine, labelled), operator, connector type, AC/DC, min power, access type, payment method, verified status; bounding-box endpoint for the map (`GET /{locale}/charging-stations/map?bbox=`, cached 60 s, max 500 markers, clustering client-side), debounced. Location permission optional — denial keeps manual search working (test the endpoint without coordinates). Directions button opens `Integrations::map()->directionsUrl(lat, lng)`.
- Member-suggested stations enter `pending_review` and are published only after admin verification. Live provider sync: `charging:sync` command using `Integrations::charging()` when configured (normalizes connector codes/status via the provider DTOs), writes `station_status_updates` and updates units; stale live data flips to unknown via `charging:expire-live-status` scheduled every 5 min.

- Member: `/account/charging` (favorites, my reports, my suggestions, compatible stations for primary vehicle), garage section `charging_stations` (compatible stations near the member's governorate).
- Admin: `/admin/charging-stations` (DataTable, filters incl. verification status, bulk verify), create/edit (AddressMapPicker, operator, units/connectors editor, tariffs, images), `/admin/charging-stations/verification` (dashboard with the five queues), reports moderation (apply → creates status update with source community, dismiss), operators CRUD, importer `ChargingStationsImporter` (CSV with lat/lng, connectors), exporter. KPIs `charging_stations_published`, `stations_needing_verification` (tone warning). Rate limiter `station-reports` (10/hour per user).
