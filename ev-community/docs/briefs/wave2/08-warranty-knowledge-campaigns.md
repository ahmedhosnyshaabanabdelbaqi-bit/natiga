## Rules
- Warranties are created automatically when other modules call `Warranties::createFromOrderItem($orderItem, ...)`/`createFromServiceRecord(...)` (public service; guard tables); manual entries by members are labelled member-added. Reminders 30/7 days (settings `warranty.reminder_days` default [30, 7]) via scheduled command + Notify with dedup keys; status expired daily.
- Claims workflow per contract; staff decisions require reason; member sees only own warranties/claims (IDOR tests); documents private.
- Articles: workflow draft → review → published (content-manager) with sanitized HTML (allow-list: p, h2-h4, ul/ol/li, strong, em, a[href http(s)], img[src from our storage], blockquote, table) — test that `<script>` is stripped; vehicle-specific articles appear in the garage section `articles` for matching vehicles; public knowledge center with categories/search/SEO; feature flag for comments not included.
- Community issues shown as "community experiences", never as diagnosis (fixed disclaimer key); reporter identity hidden publicly (only make/model/year/mileage range); admin analytics: counts by model/category/year/mileage range (no PII).
- Campaigns: published only with source + reference + verification date; matching job computes `possible` matches by rules for all member vehicles (and on vehicle create/update via event listener) → garage section `campaigns` shows "قد تنطبق هذه الحملة على سيارتك" with source link; `confirmed` only when a real lookup source is recorded by staff (manual entry with source) — no automatic VIN confirmation. Notify matched members (dedup per campaign+vehicle).

## Pages
- Public: `/{locale}/knowledge` (categories, featured, search), `/{locale}/knowledge/{category}`, `/{locale}/knowledge/articles/{slug}` (SEO, hreflang), `/{locale}/campaigns` (published recalls list with sources), `/{locale}/community-issues` (anonymised list, filters make/model/category).
- Member: `/account/warranty` (list, add manual, detail with documents, claim create/track), `/account/community-issues` (mine + create), garage sections `warranty`, `campaigns`, `articles`, `installed_parts` (reads `installed_parts` table if present, else empty state).
- Admin: `/admin/warranty` (warranties, claims board with decisions), `/admin/knowledge-base` (articles editor bilingual with vehicle relations & tags, categories), `/admin/campaigns` (CRUD, rules, sources, matches list, notify action), `/admin/community-issues` (moderation, analytics). KPIs `warranty_claims_open`, `campaign_matches_unconfirmed`; audiences `campaign_matched_members`; exporters (warranties, claims).
