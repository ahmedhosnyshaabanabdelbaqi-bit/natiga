# Implementation briefs

Each brief is the mission statement for one engineer (or AI agent) building one module group. Briefs are derived from the master product brief and are binding together with:

- `docs/CONVENTIONS.md` (engineering rules), `docs/DOMAIN_CONTRACTS.md` (table/model contracts), `docs/BUSINESS_RULES.md` (financial/operational rules)
- the wave-1 platform APIs listed in `docs/briefs/wave2/00-shared.md`

Status of each brief is tracked in `docs/TRACEABILITY.md`.
