نظام إدارة المحلات الصغيرة — نقطة البيع
=========================================

ما في هذه الحزمة
----------------
الكود المصدري كاملًا + الواجهة مبنية جاهزة في public/build.

ما ليس فيها (عمدًا):
  - vendor/       اعتماديات PHP   → يُعاد بناؤها بـ composer install
  - node_modules/ اعتماديات Node  → غير لازمة على الخادم (الواجهة مبنية بالفعل)
  - .env          ملف الأسرار     → أنشئه من .env.example


المتطلبات
---------
  PHP 8.3+ مع الامتدادات: pdo_pgsql, mbstring, intl, zip, gd, openssl, xml
  PostgreSQL 16+     ← إلزامي، النظام لا يعمل على MySQL أو SQLite
  Composer 2.x
  Node.js 20+        ← فقط إذا أردت تعديل الواجهة وإعادة بنائها


التشغيل في خمس خطوات
--------------------
  1) composer install --no-dev --optimize-autoloader

  2) cp .env.example .env
     php artisan key:generate

  3) أنشئ قاعدة البيانات:
       CREATE ROLE pos LOGIN PASSWORD 'ضع-كلمة-سر-قوية';
       CREATE DATABASE pos_prod OWNER pos;
     ثم عدّل في .env:  DB_DATABASE, DB_USERNAME, DB_PASSWORD

  4) php artisan migrate --seed

  5) وجّه خادم الويب إلى مجلد public/
     (أو للتجربة السريعة: php artisan serve)


أول دخول
--------
  المستخدم: owner

  >>> غيّرها فورًا من شاشة المستخدمين. <<<

بيانات تجريبية (اختيارية)
-------------------------
  php artisan db:seed --class=DemoDataSeeder


التوثيق الكامل في مجلد docs/
----------------------------
  INSTALL.md              التثبيت المحلي والسحابي، Nginx، المجدول، التقوية
  USER-GUIDE-CASHIER.md   دليل الكاشير
  USER-GUIDE-OWNER.md     دليل المالك
  HARDWARE.md             الباركود والطباعة وقائمة التوافق
  BACKUP.md               النسخ الاحتياطي والاستعادة
  ARCHITECTURE.md         خريطة الوحدات وقواعد العمل الحرجة
  DATABASE.md             مخطط قاعدة البيانات والقيود
  API.md                  توثيق 96 مسارًا
  DESIGN.md               نظام التصميم والوضع الليلي
  TESTS.md                الاختبارات ونتائجها وأرقام الأداء
  STATUS.md               *** حالة كل وحدة بصراحة، وما لم يُنفَّذ ***


مهم قبل التشغيل الحقيقي
-----------------------
  - اقرأ docs/STATUS.md: يذكر بوضوح ما هو مكتمل ومختبر، وما هو منفَّذ بلا
    اختبار، وما هو غير منفَّذ (الطباعة الصامتة، تكامل الدفع، الفواتير
    الإلكترونية، الصيدليات).
  - اضبط النسخ الاحتياطي: POS_BACKUP_PASSPHRASE في .env، ونسخة خارج
    جهاز التشغيل. راجع docs/BACKUP.md.
  - اختبر الطابعة والقارئ على أجهزتك فعليًا قبل يوم العمل الأول.
