# دليل النسخ الاحتياطي والاستعادة

> **قاعدة:** نسخة لم تُختبر استعادتها ليست نسخة احتياطية.
> اختبار الاستعادة الآلي جزء من مجموعة الاختبارات (`tests/Concurrency/BackupRestoreTest.php`).

---

## 1. ماذا تفعل النسخة

```bash
php artisan pos:backup --path=/var/backups/pos --keep=14
```

1. `pg_dump` بصيغة `custom` (مضغوطة وقابلة للاستعادة الانتقائية)
2. تشفير **AES-256-CBC** مع `PBKDF2` و200,000 تكرار وملح عشوائي
3. كتابة ملف بصمة `.json` بجانبها يحمل:
   - عدد الفواتير وإجمالي المبيعات
   - إجمالي المرتجعات
   - كمية وقيمة المخزون
   - أرصدة الخزائن ومديونيات العملاء
   - إجمالي القيود المحاسبية وعدد سجلات التدقيق
   - `sha256` للملف نفسه
4. حذف النسخ الأقدم من حد `--keep`

**مفتاح التشفير خارج الكود:** متغير البيئة `POS_BACKUP_PASSPHRASE`.
بدونه يرفض الأمر العمل ولا يُنشئ نسخة غير مشفرة تلقائيًا.

```bash
# للتطوير فقط
php artisan pos:backup --no-encrypt
```

## 2. الجدولة

مضبوطة في `routes/console.php`:

```php
Schedule::command('pos:backup --keep=14')->twiceDaily(2, 14);
```

يكفي إدخال cron واحد:
```cron
* * * * * cd /var/www/pos && php artisan schedule:run >> /dev/null 2>&1
```

## 3. سياسة الاحتفاظ الموصى بها

| النوع | التكرار | الاحتفاظ | المكان |
|---|---|---|---|
| تلقائية | مرتان يوميًا (2ص و2م) | 14 نسخة | قرص الخادم |
| يومية خارجية | يوميًا بعد الإغلاق | 30 يومًا | **قرص خارجي أو جهاز آخر** |
| شهرية | أول كل شهر | 12 شهرًا | تخزين بعيد |

**نسخة خارج جهاز التشغيل إلزامية.** قرص الخادم يتعطل مع الخادم.

```bash
# مثال: مزامنة يومية لجهاز آخر في الشبكة
rsync -az --delete /var/backups/pos/ backup@192.168.1.20:/backups/pos/
```

## 4. الاستعادة

### الطريقة الآمنة: استعد إلى قاعدة منفصلة أولًا

```bash
sudo -u postgres createdb pos_restore_check -O pos_app

php artisan pos:restore /var/backups/pos/pos_20260922_020000.dump.enc \
  --database=pos_restore_check --verify --force
```

مثال المخرجات عند النجاح:

```
تمت الاستعادة إلى [pos_restore_check].
تم التحقق: كل الأرصدة والمستندات مطابقة للنسخة الأصلية.
  - sales_count: 1
  - sales_total: 450.0000
  - returns_total: 150.0000
  - stock_qty: 17.0000
  - stock_value: 1530.000000
  - cash_balance: 850.0000
  - customer_balance: 200.0000
  - journal_debit: 2280.0000
  - audit_count: 9
```

`--verify` يعيد حساب البصمة على البيانات المستعادة ويقارنها **حقلًا بحقل**.
أي اختلاف ⇒ خروج بكود فشل وبيان الحقول المختلفة.

### الاستعادة الفعلية على قاعدة التشغيل

```bash
php artisan down                          # أوقف البيع أولًا
php artisan pos:restore <الملف> --verify  # استعادة وتحقق
php artisan up
```

## 6. ما لا يشمله النسخ

| العنصر | الحالة | ما يجب فعله |
|---|---|---|
| صور المنتجات والمرفقات (`storage/app`) | **غير مشمولة** | انسخها بشكل منفصل |
| ملف `.env` والأسرار | **غير مشمول عمدًا** | احفظه في مكان آمن منفصل |
| العمليات المحلية على أجهزة الكاشير (IndexedDB) | **غير مشمولة** | زامنها قبل أي صيانة، أو صدّرها من شاشة المزامنة |

```bash
# نسخ الملفات المرفوعة
tar czf /var/backups/pos/storage_$(date +%F).tar.gz storage/app
```

---

## 7. تخزين المتصفح ليس نسخة احتياطية

العمليات المحلية في وضع فقد الخادم تُحفظ في **IndexedDB** على جهاز الكاشير.
هذا التخزين قد يُمسح بـ: تنظيف بيانات الموقع · التصفح الخاص · استرداد النظام للمساحة.

لذلك:
- الشاشة تعرض دائمًا **عدد العمليات غير المتزامنة**
- زر **«تصدير العمليات المعلقة»** يحفظ ملف JSON قبل أي صيانة
- **لا يُغلق** إغلاق نهائي لوردية بها عمليات غير متزامنة إلا بمسار استثناء باعتماد مدير،
  ويُسجَّل عددها في `shifts.unsynced_operations_at_close`
