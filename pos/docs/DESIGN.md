# نظام التصميم

الواجهة كلها مبنية على **مجموعة توكنز واحدة** في `resources/css/app.css`.
لا لون ولا نصف قطر ولا ظل مكتوب مباشرة في مكوّن.

---

## 1. المبادئ

| المبدأ | كيف طُبِّق |
|---|---|
| **العربية و RTL أصلًا** | `dir="rtl"` على الجذر، وكل التباعد بـ `start/end` لا `left/right` |
| **الأرقام لا ترقص** | `.num` يفرض اتجاه LTR وعرض خانات ثابتًا (`tabular-nums`) |
| **الحركة لا تعترض الكاشير** | أقصى مدة 140 مللي، وتُلغى مع `prefers-reduced-motion` |
| **لا اعتماد خارجي** | الخط والأيقونات محليان — شاشة البيع تعمل دون إنترنت |
| **الوضع الليلي مجاني** | نفس التوكنز بقيم أخرى؛ لا فئة `dark:` واحدة في المكوّنات |

---

## 2. التوكنز

### الأسطح والنصوص

| التوكن | الاستخدام |
|---|---|
| `surface-0` | خلفية الصفحة |
| `surface-1` | البطاقات والأسطح المرتفعة |
| `surface-2` | مناطق غائرة، رؤوس الجداول، أشرطة الأدوات |
| `surface-3` | حالة التمرير |
| `line` / `line-strong` | حدود خفيفة / واضحة |
| `ink` / `ink-muted` / `ink-subtle` | نص أساسي / ثانوي / خافت |
| `chrome` / `chrome-2` / `chrome-3` | الشريط الداكن، ثابت في الوضعين |

### الهوية والدلالات

| التوكن | المعنى |
|---|---|
| `brand` · `brand-strong` · `brand-deep` · `brand-soft` | الهوية والإجراءات الأساسية |
| `cash` · `cash-strong` · `cash-soft` | المال والتأكيد الناجح — **زر الدفع** |
| `warn` · `warn-strong` · `warn-soft` | تحذير، **الباقي للعميل**، مستند غير متزامن |
| `danger` · `danger-strong` · `danger-soft` | رفض، حذف، مرتجع |
| `info` · `info-soft` | معلومة محايدة |

**قاعدة:** الأخضر (`cash`) محجوز للمال والنجاح. الأزرار الأساسية غير المالية
تستخدم `brand`. هذا يجعل زر الدفع مميزًا بصريًا دون كلمات.

### الوضع الليلي

يُطبَّق بإعادة تعريف نفس المتغيرات تحت:
- `@media (prefers-color-scheme: dark)` مع `:root:not([data-theme='light'])`
- `:root[data-theme='dark']` للاختيار اليدوي

الاختيار يُحفظ لكل جهاز (`pos.theme` في `localStorage`) ويُطبَّق **قبل** إنشاء
التطبيق في `app.ts` تفاديًا لوميضة بيضاء على شاشة معتمة.

## 3. الأنماط المشتركة

| الأداة | الغرض |
|---|---|
| `.card` | سطح + حد + ظل خفيف |
| `.field` / `.field-lg` | حقول الإدخال بحلقة تركيز موحّدة |
| `.num` | أرقام LTR بعرض ثابت |
| `.t-fast` | انتقال 120 مللي للألوان والظل |
| `.t-pop` | انكماش 0.97 عند الضغط — تغذية لمسية |
| `.scroll-slim` | شريط تمرير نحيف |
| `.safe-b` | هامش سفلي آمن على الأجهزة ذات الحواف |
| `.clamp-2` | قص النص بعد سطرين |

حلقة التركيز موحّدة عبر `:focus-visible` في مكان واحد — لا مكوّن يعيد تعريفها.

## 4. الأيقونات

`resources/js/components/AppIcon.vue` — مجموعة SVG مضمّنة بنمط خطي موحّد
(`stroke-width: 1.75`).

```vue
<AppIcon name="cart" :size="18" />
```

**لا خط أيقونات ولا CDN.** أيقونة مفقودة في لحظة انقطاع الشبكة تعني واجهة
غير مفهومة، وهذا غير مقبول على شاشة كاشير.

كل زر أيقوني يحمل `aria-label` — التلميح وحده لا يكفي لقارئ الشاشة ولا للاختبار.

---

## 5. الخط

`resources/css/fonts.css` — خط **Cairo** مستضاف محليًا في `public/fonts/`.

Cairo خط **متغيّر**: ملف واحد لكل نطاق محارف (عربي، لاتيني، لاتيني موسّع) يغطي
الأوزان 400–900، والمتصفح لا ينزّل نطاقًا لا يعرضه. الحجم الكلي **92 كيلوبايت**.

> كان الخط يُحمَّل من CDN خارجي. على نظام يَعِد بالعمل دون إنترنت كان ذلك
> تناقضًا: أول انقطاع يعني واجهة بخط بديل. الاستضافة المحلية أزالت الاعتماد.

## 6. تخطيط شاشة البيع

```
┌──────────────────────────────────────────────────────┐
│ شريط داكن: الجهاز · الوردية · الاتصال · أدوات         │
├──────────────────────────────────────────────────────┤
│ [مسح الباركود F3]      [بحث F2]         [المفضلة]    │
├──────────────────────┬───────────────────────────────┤
│                      │                               │
│   🛒 السلة (يمين)    │   شبكة الأصناف                │
│                      │                               │
│  ────────────────    │                               │
│  الإجمالي (ثابت)     │                               │
│  [دفع F9]            │                               │
│  [تعليق][معلقة][مرتجع]│                               │
└──────────────────────┴───────────────────────────────┘
```

قرارات مقصودة:

- **السلة يمينًا**: في العربية تقع العين هناك أولًا.
- **الإجمالي وزر الدفع لا يتحركان**: الكاشير يصل إليهما دون نظر.
- **خانة المسح دائمة التركيز** وتستعيده بعد كل إضافة، لكنها **لا تسرقه** أثناء
  كتابة مبلغ (`data-keep-focus="true"`).
- **الشبكة تُحمَّل عند الإقلاع** حتى في وضع الباركود — نصف شاشة فارغ هدر.
- **اختصارات ظاهرة** على الأزرار (`F7`, `F4`, `F8`, `F9`) لأن التعلّم يحدث بالاستخدام.

## 7. أدوات التحقق البصري

```bash
npm run typecheck   # vue-tsc
npm run build       # typecheck + build
npm run smoke       # دورة بيع كاملة في متصفح حقيقي
npm run sweep       # كل الشاشات، نهاري وليلي: أخطاء، شاشة فارغة، تمرير أفقي
```

`sweep` و`smoke` يحتاجان خادمًا يعمل وبيانات تجريبية:

```bash
php artisan migrate:fresh --seed
php artisan db:seed --class=DemoDataSeeder
php artisan serve --port=8899 &
npm run sweep
```

اللقطات تُحفظ في `storage/app/smoke/` (مستثناة من git).
