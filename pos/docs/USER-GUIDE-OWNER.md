# دليل المالك

## أول تشغيل: معالج الإعداد

عند فتح النظام لأول مرة يبدأ المعالج بسبع خطوات — **يكفي إتمام الأولى والثانية للبدء**:

| # | الخطوة | إلزامي؟ |
|---|---|---|
| 1 | بيانات المحل ونوع النشاط والعملة والتوقيت | نعم |
| 2 | الفرع | نعم (جاهز مسبقًا) |
| 3 | المخزن | نعم (جاهز مسبقًا) |
| 4 | جهاز الكاشير | نعم (جاهز مسبقًا) |
| 5 | المستخدمون | يمكن تخطيه |
| 6 | الضرائب | يمكن تخطيه |
| 7 | إنهاء | — |

### اختيار نوع النشاط يفعّل المزايا المناسبة له فقط

| النشاط | ما يُفعَّل تلقائيًا |
|---|---|
| بقالة وميني ماركت | الأوزان، الدفعات والصلاحية، الوحدات المتعددة |
| ملابس وأحذية | المقاسات والألوان |
| موبايلات وإكسسوارات | الأرقام التسلسلية، الضمان، المتغيرات |
| مستحضرات تجميل وعطور | الدفعات والصلاحية، المتغيرات |
| أدوات منزلية / مكتبية | الوحدات المتعددة |
| كهرباء وسباكة وعدد | الوحدات المتعددة، الأوزان |
| قطع غيار | الوحدات المتعددة |

> **تغيير الاختيار لاحقًا لا يفقد البيانات.** تعطيل ميزة يخفي واجهتها فقط؛
> ما سُجِّل بها يبقى ويظهر مجددًا عند إعادة التفعيل.
> عدّل أي ميزة من **الإعدادات → مزايا النشاط**.

### الضرائب

النظام **لا يفترض** نسبة ضريبة ولا التزامًا قانونيًا. تفعّلها أنت وتُدخل النسبة.

> ⚠️ تفعيل حساب الضريبة **لا يعني** الامتثال لمنظومة الفواتير الإلكترونية.
> ذلك يحتاج تكاملًا منفصلًا ومختبرًا **غير منفَّذ في هذا الإصدار**.

## إدخال الأصناف

### يدويًا
**الأصناف → صنف جديد**: الكود، الاسم، الوحدة، الباركود، سعر التجزئة والجملة،
عدد القطع بالكرتونة، الحد الأدنى.

### بالاستيراد (مُستحسن للبداية)

1. نزّل **قالب CSV** (عربي، جاهز لـ Excel)
2. املأه
3. ارفعه → **يعرض المعاينة والأخطاء بأرقام الصفوف قبل الحفظ**
4. صحّح أو اختر تجاهل الصفوف غير الصالحة → حفظ

الأعمدة: `sku, name, name_en, barcode, unit, category, cost, price, wholesale_price, opening_qty, min_stock, carton_factor`

> **الرصيد الافتتاحي يُسجَّل كاستلام بضاعة موثّق**، لا ككتابة مباشرة على الرصيد —
> فيبقى كل جنيه في المخزون مفسَّرًا.

## المستخدمون والصلاحيات

خمسة أدوار جاهزة: **المالك · مدير الفرع · كاشير · محاسب · أمين المخزن**.

الصلاحيات **مفصولة عمدًا**:

| الصلاحية | لماذا مفصولة |
|---|---|
| `sales.view_cost` | رؤية التكلفة والربح |
| `sales.change_price` | تعديل سعر البيع |
| `sales.discount` | منح خصم |
| `sales.discount.override` | اعتماد خصم يتجاوز سقف الكاشير |
| `sales.return` | تنفيذ مرتجع |
| `sales.credit` | البيع الآجل |
| `cash.drawer.open` | فتح الدرج بدون بيع |
| `inventory.adjust` | تسوية المخزون |
| `cash.shift.close` | إغلاق الوردية |
| `reports.export` | تصدير البيانات |

**الصلاحيات تُطبَّق على الخادم.** إخفاء الزر ليس حماية — لو حاول كاشير طلب
التكلفة مباشرة عبر الـAPI، تُحذف من الاستجابة.

**سقف الخصم لكل مستخدم:** نسبة ومبلغ. تجاوزه يطلب موافقة مدير
**بحسابه الشخصي** — لا كود مدير مشترك، ولا يعتمد أحد طلبه بنفسه.

## لوحة المالك

| الرقم | تعريفه |
|---|---|
| **مبيعات اليوم (إجمالي)** | مجموع الفواتير المعتمدة شامل الضريبة |
| **المرتجعات** | مجموع المرتجعات في نفس الفترة |
| **صافي المبيعات** | الإجمالي − المرتجعات |
| **مجمل الربح** | صافي المبيعات − الضريبة المحصلة − تكلفة البضاعة المباعة |
| **الربح التشغيلي** | مجمل الربح − المصروفات المسجلة |

> **الإيراد النقدي ليس ربحًا.** المبلغ في الدرج يشمل تحصيلات ديون قديمة ولا يطرح التكلفة.
> **شراء البضاعة ليس مصروفًا.** المشتريات تنتقل للمخزون، ولا تصل لخط الربح إلا كتكلفة مبيعات
> عند البيع فعلًا.

**اضغط أي رقم لترى المستندات التي كوّنته.**

## التقارير

| التقرير | المحتوى |
|---|---|
| المبيعات حسب الفترة | يومي/أسبوعي/شهري مع الخصومات والضريبة |
| توزيع طرق الدفع | نقدي، بطاقة، محفظة، تحويل |
| الأصناف الأعلى والأقل حركة | الكمية والإيراد والربح |
| تقييم المخزون | بالمتوسط المرجح المتحرك |
| مديونيات العملاء والموردين | الأرصدة والاستحقاقات |
| فروق الورديات | العجز والزيادة لكل وردية |

كل التقارير تستخدم **نفس تعريف يوم العمل** وتوقيت المحل، فلا تتناقض.

## المخزون

- **كل تغيّر كمية له حركة موثّقة** بمصدر وسبب ومستخدم ووقت
- **الأرصدة مشتقة** من سجل الحركات، وزر **«مطابقة الأرصدة بالحركات»**
  يثبت التطابق أو يكشف الفروق
- **المخزون السالب ممنوع** افتراضيًا
- **التنبيهات**: نقص المخزون، قرب انتهاء الصلاحية، الأصناف الراكدة، الفواتير المتأخرة

### الجرد
يُلتقط رصيد مبدئي، وأثناء العد يستمر البيع. عند الاعتماد:

```
الفرق = المعدود − (الرصيد المبدئي + حركات حدثت أثناء الجرد)
```

فلا تظهر مبيعات وقت الجرد كعجز.

---

## المشتريات

**أمر الشراء لا يزيد المخزون.** الكمية والتكلفة تتغيران عند **الاستلام** فقط،
ويمكن الاستلام على دفعات.

كل استلام يحدّث **المتوسط المرجح المتحرك** للتكلفة ويقيّد المستحق للمورد.

---

## الورديات والخزنة

```
النقد المتوقع = العهدة + مقبوضات نقدية − الباقي المصروف
                + التحصيلات والإيداعات
                − المرتجعات النقدية − المصروفات والسحوبات
```

- **العد الأعمى** مفعّل: الكاشير لا يرى المتوقع قبل تسجيل الفعلي
- الفرق يُحسب ويُسجَّل، وتسويته تحتاج **اعتمادًا مسجلًا** في سجل التدقيق
- **لا تُعدَّل وردية مغلقة بصمت**

---

## المزامنة والتعارضات

شاشة **المزامنة** تعرض ما لم يُقبل كما أُرسل من أجهزة عملت دون خادم.

لكل عملية: الجهاز، الوقت، **المبلغ الذي حُصِّل من العميل**، وسبب التعارض.
تختار **اعتماد** (يُعاد التنفيذ بصلاحيتك والخادم يعيد حساب الأسعار) أو **رفض** بسبب.

> **لا يُمسح سجل ولا يُعدَّل مبلغ محصَّل بصمت.** كل قرار يُسجَّل في التدقيق.

---

## سجل التدقيق

يسجّل: الخصومات فوق السقف · تعديل الأسعار · المرتجعات · فتح الدرج ·
تسويات المخزون · إغلاق وتسوية الورديات · تغيير الصلاحيات · إعادة الطباعة · تسوية التعارضات.

لكل سجل: المستخدم، الوقت، الجهاز، السبب، والقيم قبل وبعد.

> **السجل غير قابل للتعديل من واجهة التشغيل** — قاعدة البيانات نفسها ترفض التعديل والحذف.
> لا تُسجَّل كلمات مرور ولا بيانات بطاقات.

## النسخ الاحتياطي

- نسخ **مشفّرة** تلقائية مرتين يوميًا
- **احتفظ بنسخة خارج جهاز التشغيل**
- **اختبر الاستعادة شهريًا**: `php artisan pos:restore <الملف> --database=pos_restore_check --verify`

راجع `docs/BACKUP.md`.

## ما لا يقدّمه هذا الإصدار — بصراحة

| البند | الحالة |
|---|---|
| الصيدليات والأنشطة المنظمة | **غير مدعوم** — يحتاج وحدات مستقلة، وإضافة منتجات لا تكفي |
| الامتثال لمنظومة الفواتير الإلكترونية | **غير منفَّذ** — النظام يحسب الضريبة فقط |
| تكامل بنكي تلقائي للدفع | **غير منفَّذ** — المدفوعات غير النقدية تسجيل يدوي |
| الطباعة الصامتة وفتح الدرج آليًا | **يحتاج وسيطًا محليًا غير منفَّذ** |
| ميزان بمنفذ مباشر، شاشة عميل | **غير منفَّذة** |
| متجر إلكتروني | **غير منفَّذ** — الـAPI جاهز للتكامل لاحقًا |

القائمة الكاملة في `docs/STATUS.md`.
