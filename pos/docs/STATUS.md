# حالة كل وحدة — بصراحة

ثلاث حالات فقط:

- ✅ **مكتملة ومختبرة** — منفَّذة، ولها اختبار آلي يمر
- 🟡 **منفَّذة ولم تُختبر آليًا** — الكود موجود ويعمل، بلا اختبار مخصص
- ⛔ **غير منفَّذة** — لا يوجد كود، ولا تُعرض أزرار لها

## غير منفَّذ — لا توجد أزرار له

| البند | لماذا |
|---|---|
| ⛔ **وسيط الطباعة الصامتة** | يحتاج برنامجًا يُثبَّت على جهاز الكاشير. طبقة التكامل مفصولة، والوسيط نفسه غير مكتوب |
| ⛔ **فتح درج النقدية آليًا** | يتبع الوسيط أعلاه. الفتح اليدوي مسجَّل ومحمي بصلاحية |
| ⛔ **ميزان بمنفذ تسلسلي مباشر** | يحتاج الوسيط. الموازين التي تطبع باركود موزون **مدعومة** |
| ⛔ **شاشة العميل** | وحدة اختيارية |
| ⛔ **تكامل مزود دفع** | المدفوعات غير النقدية **تسجيل يدوي** (`capture_mode = manual`). الحقول والحالات جاهزة |
| ⛔ **الربط بمنظومة الفواتير الإلكترونية** | لا ادعاء امتثال. النظام يحسب الضريبة ويفصلها فقط |
| ⛔ **نقاط الولاء والكوبونات والعمولات** | جداول ومفاتيح مزايا موجودة؛ المنطق غير مكتوب |
| ⛔ **الحجوزات والتوصيل** | مفاتيح مزايا فقط |
| ⛔ **متجر إلكتروني** | الـAPI ومنع التكرار جاهزان للتكامل لاحقًا؛ لا متجر مبني |
| ⛔ **وحدة الصيدليات** | تحتاج متطلبات مستقلة. **إضافة منتجات لا تجعل النظام صالحًا لها** |
| ⛔ **تعدد الشركات / SaaS** | خارج نطاق الإصدار الأول عمدًا |
| ⛔ **مزامنة قواعد بيانات متعددة** | قاعدة مرجعية واحدة لكل نشر |

## قيود تحتاج أجهزة أو إعدادات خارجية

| البند | ما تحتاجه |
|---|---|
| الطابعة الحرارية | تعريف من الشركة المصنعة وضبط مقاس الورق. القوالب جاهزة، **اختبر الطباعة بنفسك** |
| قارئ الباركود | ضبط `Suffix = Enter` ولوحة مفاتيح إنجليزية |
| باركود الموازين | إدخال صيغة الميزان في الإعدادات — لا توجد صيغة واحدة لكل الموازين |
| النسخ الاحتياطي | `POS_BACKUP_PASSPHRASE` + مكان تخزين **خارج جهاز التشغيل** |
| النشر السحابي | شهادة HTTPS ونطاق |
| الخادم المحلي | IP ثابت وشبكة سلكية مفضّلة للكاشيرات |

## الخلاصة

يمكن لمحل صغير **تشغيل هذا النظام فعليًا اليوم** لـ:
البيع النقدي والمختلط والآجل · الباركود والوحدات المتعددة والسيريال ·
المرتجعات · الورديات والخزنة · المخزون والتكلفة · المشتريات والاستلام ·
العملاء والتحصيل · التقارير · العمل المحدود دون خادم · النسخ الاحتياطي.

وما لا يفعله مذكور أعلاه **بلا تجميل**.
