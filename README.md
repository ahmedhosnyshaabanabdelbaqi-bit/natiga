# EG Distribution ERP

نظام تشغيل لشركة توزيع: مشتريات، مخازن، مبيعات، مناديب وسيارات، تحصيل،
حسابات قيد مزدوج، وتقارير.

> الاسم والشعار والألوان وبيانات الشركة **قابلة للتغيير بالكامل** من
> الإعدادات ← بيانات الشركة. لا يوجد اسم شركة مكتوب داخل الكود.

## ابدأ من هنا

**[`docs/09-status.md`](docs/09-status.md)** — ما هو منفذ ومُختبَر، وما هو مكتوب
ولم يُختبر، وما هو **غير منفذ إطلاقًا**. اقرأه قبل أي قرار تشغيلي.

## التشغيل السريع

```bash
cd erp
cp .env.example .env          # اضبط ERP_OWNER_PASSWORD
docker compose up
```

الواجهة على `http://localhost:5173`، وواجهة API على `http://localhost:8000`.

للتثبيت اليدوي: [`docs/08-install.md`](docs/08-install.md).

## المبادئ التي لا يُتنازل عنها

هذه مفروضة في الكود ومغطّاة باختبارات — **98 اختبارًا، 301 تحقّقًا، جميعها ناجحة**:

1. **مصدر واحد للترحيل.** السيرفر وحده يُنشئ حركة مخزنية أو قيدًا. الأجهزة
   الميدانية ترسل «عمليات» لا «نتائج».
2. **الذرّية.** المستند وحركاته وقيده في معاملة واحدة: تنجح كلها أو تتراجع كلها.
3. **عدم التكرار.** لكل عملية مفتاح فريد؛ إعادة الإرسال تُعيد الإيصال الأصلي ولا
   تُنشئ مستندًا ثانيًا.
4. **لا تعديل للماضي.** المستند المعتمد يحفظ سعره وخصمه وضريبته ومعامل وحدته.
   التصحيح بعكس أو إشعار، لا بحذف.
5. **الرفض الافتراضي.** كل مسار API يعلن صلاحيته؛ المسار الذي لا يعلن يُرفض.
6. **لا Float في المال.** كل المبالغ والكميات `NUMERIC`.
7. **لا مخزون سالب.** قيد `CHECK` في قاعدة البيانات، لا فحص في الواجهة.

## ما يميّز هذا التنفيذ

- **الخصم المزدوج مستحيل هيكليًا**: إذن التسليم يُخرج البضاعة، والفاتورة بعده لا
  تلمس المخزون. مُثبت باختبار.
- **التكلفة التاريخية مجمّدة**: شراء أغلى اليوم لا يغيّر ربح فاتورة الأسبوع الماضي.
- **الفعلي ≠ المتاح ≠ القابل للبيع**: بالطريق والحجر والفحص والتالف بضاعة حقيقية
  لا تُباع.
- **التحصيل ليس إيرادًا**: نقدية المندوب في عهدته حتى يوردها بمحضر معتمد،
  والتوريد ينقل أصلًا بين حسابين.
- **الشيك ليس نقدية** حتى يُحصَّل.
- **مجمل الربح ليس صافي الربح**، ومكتوب هكذا في كل شاشة.
- **البيع الأوفلاين مقيّد** بمخزون السيارة وحصة ائتمان محجوزة وتفويض محدد المدة.
  ما عدا ذلك **طلب مبدئي** يقوله التطبيق صراحةً.
- **التعارضات تُعرض للمراجعة البشرية**؛ «آخر تعديل يفوز» ممنوعة في المال والمخزون.
- **تتبع الموقع أثناء الوردية فقط** وبإذن صريح، وتُعرض القراءة بعمرها ودقتها مع
  تنبيه بأن ضعف الإشارة ليس دليل مخالفة.

## الاختبارات

```bash
cd erp/api
php artisan migrate:fresh --env=testing --force
vendor/bin/phpunit
```

تعمل على PostgreSQL لا SQLite، لأن المخطط يعتمد على triggers مؤجلة وفهارس فريدة
جزئية ودقة `NUMERIC` — والاختبار على محرك آخر يثبت شيئًا لا يعمل عليه النظام.
