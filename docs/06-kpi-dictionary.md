# قاموس المؤشرات

كل مؤشر في لوحة التحكم يحمل تعريفه معه في الواجهة نفسها، ورابطًا إلى المستندات
المكوِّنة له. الرقم الذي لا يستطيع أحد فتحه هو رقم لا يثق به أحد.

## 1. تمييزات لا يُتهاون فيها

| ليس | نفس | ولماذا |
|---|---|---|
| المبيعات | التحصيلات | البيع الآجل مبيعات بلا نقدية |
| مجمل الربح | صافي الربح | مجمل الربح لا يطرح المصروفات التشغيلية |
| الرصيد الفعلي | المتاح للبيع | المحجوز والحجر والتالف وبالطريق ليست متاحة |
| قيمة المخزون | قيمة البيع | التقييم بالتكلفة لا بسعر البيع |
| النقدية مع المندوب | التحصيلات | الشيك والتحويل البنكي تحصيل وليسا نقدية في اليد |

## 2. التعريفات

### صافي المبيعات
```
Σ (إجمالي الفواتير المرحّلة − ضريبتها)
− Σ (إجمالي المرتجعات المرحّلة − ضريبتها)
```
الفترة: تاريخ الفاتورة. المسودات والملغاة مستبعدة. الضريبة مستبعدة لأنها تُحصَّل
لصالح الجهة الضريبية ولا تُكتسب.

### تكلفة البضاعة المباعة
```
Σ cogs_amount للفواتير المرحّلة − Σ cogs_amount للمرتجعات المرحّلة
```
بالتكلفة **المجمّدة وقت خروج البضاعة**، لا بمتوسط اليوم.

### مجمل الربح
```
صافي المبيعات − تكلفة البضاعة المباعة
```
**ليس صافي الربح.** لا يشمل الوقود ولا الصيانة ولا الرواتب ولا أي مصروف تشغيلي،
لأن هذه لا تُنسب إلى مستند بيع بعينه. صافي الربح يُقرأ من قائمة الدخل.

### هامش الربح
```
(مجمل الربح ÷ صافي المبيعات) × 100
```
صفر إذا كان صافي المبيعات صفرًا.

### التحصيلات
```
Σ قيمة سندات القبض المرحّلة في الفترة
```
الفترة: تاريخ السند. **مستقلة تمامًا عن المبيعات**: قد تحصّل اليوم فاتورة الشهر
الماضي.

### المديونيات القائمة
```
Σ (الإجمالي − المسدد − المرتجع) للفواتير المرحّلة حيث الناتج موجب
```
كما في تاريخه، لا في نهاية الفترة.

### المتأخرات
الجزء من المديونيات الذي تجاوز `due_date`. **حسب تاريخ الاستحقاق لا تاريخ
الفاتورة** — فاتورة بمهلة 30 يومًا عمرها 20 يومًا ليست متأخرة.

### قيمة المخزون
```
Σ (الرصيد الفعلي × المتوسط المرجح المتحرك)
```
بسعر التكلفة. تشمل الحجر والفحص والتالف وبالطريق لأنها مملوكة فعلًا.

### عهد المناديب النقدية
```
Σ أرصدة حسابات العهدة النقدية (مدين − دائن)
```
نقدية حُصّلت ولم تُورَّد للخزنة. **الشيكات في عهدة منفصلة.**

### بضاعة مستلمة غير مفوترة
```
Σ ((المستلم − المفوتر) × تكلفة الاستلام)
```
يجب أن يطابق رصيد حساب `grni`. اختلافهما مؤشر على مشكلة ترحيل.

### نسبة الزيارات المنتجة
```
(الزيارات التي نتج عنها طلب أو تحصيل أو مرتجع ÷ الزيارات المنفذة) × 100
```

### نسبة تحقيق المستهدف
```
(المحقق ÷ المستهدف) × 100
```
أساس المستهدف (قيمة/كمية/ربح/تحصيل) محفوظ على سجل المستهدف نفسه.

### النقدية المتوقعة عند إقفال اليوم
```
  أول المدة
+ المقبوضات النقدية + العهد النقدية المستلمة
− الإيداعات المعتمدة − المصروفات النقدية المعتمدة
− المبالغ النقدية المردودة للعملاء
= النقدية المتوقعة
```
**الشيكات والتحويلات البنكية غير داخلة.** أول المدة يُقرأ من رصيد حساب العهدة
في الدفاتر، لا من رقم مُدخَل.

## 3. المصالحات الدورية

| الرقم | يطابق |
|---|---|
| قيمة المخزون | رصيد حساب `inventory` |
| المديونيات القائمة | رصيد حساب ذمم العملاء |
| بضاعة مستلمة غير مفوترة | رصيد حساب `grni` |
| عهد المناديب | مجموع أرصدة حسابات العهدة |
| إجمالي مدين ميزان المراجعة | إجمالي دائنه |

آخر سطر مضمون هيكليًا: شاشة ميزان المراجعة تعرض علامة `is_balanced`، وإذا ظهرت
`false` فهذا يعني أن شيئًا كُتب في اليومية خارج محرك الترحيل ويجب فحصه قبل
الاعتماد على أي تقرير مالي.
