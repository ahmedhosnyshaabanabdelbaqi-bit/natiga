## المعمارية المقصودة

تطبيق Android أصلي (**ليس WebView**) بقاعدة بيانات محلية مشفرة وصف عمليات دائم.

```
lib/
  core/        الإعدادات والألوان والثيم العربي RTL
  data/        قاعدة البيانات المحلية المشفرة + صف المزامنة + عميل API
  features/
    auth/      الدخول وتسجيل الجهاز
    sync/      المزامنة وحالتها والتعارضات
    customers/ عملاء المندوب وخطة الزيارات
    sales/     فاتورة بيع ميدانية
    collection/ سند تحصيل ميداني
```

## ضمانات التصميم

| الضمان | كيف |
|---|---|
| لا تكرار عند إعادة الإرسال | كل عملية لها `uuid` و`idempotency_key` ثابتان يُولَّدان مرة واحدة ويُحفظان قبل أي إرسال |
| لا ضياع عند إغلاق التطبيق | العملية تُكتب في `outbox` المحلي **قبل** محاولة الإرسال |
| انقطاع بعد حفظ السيرفر | إعادة المحاولة بنفس المفتاح تُرجع الإيصال المحفوظ (`replayed: true`) |
| لا «آخر تعديل يفوز» | الجهاز لا يرحّل شيئًا؛ السيرفر هو المصدر المركزي الوحيد |
| البيع الأوفلاين مقيد | حصة مخزون وحصة ائتمان مخصصتان للجهاز تُسحبان في `pull` |
| التفويض محدود المدة | `offline_authorized_until` — بعدها يتوقف إنشاء عمليات جديدة |
| الرقم الميداني ≠ المركزي | `field_no` محلي، و`doc_no` يأتي من إيصال السيرفر |

## البناء

```bash
cd erp/mobile
flutter pub get
flutter run                     # تطوير على جهاز موصول
flutter build apk --release     # حزمة إصدار
```

### توقيع نسخة الإنتاج

1. أنشئ مخزن مفاتيح:
   ```bash
   keytool -genkey -v -keystore fayad.jks -keyalg RSA -keysize 2048 -validity 10000 -alias fayad
   ```
2. أنشئ `android/key.properties` (**لا يُرفع للمستودع**):
   ```
   storePassword=…
   keyPassword=…
   keyAlias=fayad
   storeFile=../fayad.jks
   ```
3. اربطه في `android/app/build.gradle` بقسم `signingConfigs`.
4. `flutter build appbundle --release` للنشر على Google Play، أو `--split-per-abi` لحزم APK أصغر.
