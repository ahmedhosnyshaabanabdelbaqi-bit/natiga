# تطبيق المندوب — EG Distribution

تطبيق Android أصلي (Flutter/Dart)، وليس WebView.

## حالة التنفيذ — اقرأ هذا أولًا

| المكوّن | الحالة |
|---|---|
| نموذج البيانات المحلي وطابور العمليات | كود مكتوب، **غير مُختبَر على جهاز** |
| بروتوكول المزامنة (Idempotency، الترتيب، التعارض) | كود مكتوب ومتوافق مع عقد السيرفر المُختبَر |
| شاشات العملاء والطلب والتحصيل | كود مكتوب، **غير مُختبَر على جهاز** |
| مسح الباركود | مكتبة مُعرّفة، **يحتاج اختبارًا على جهاز فعلي** |
| الطباعة المحمولة | **غير منفذة** — تحتاج طراز طابعة محددًا واختبارًا فعليًا |
| الخرائط والملاحة | **غير منفذة** |

> **لم يتم بناء هذا التطبيق أو تشغيله.** بيئة التطوير التي أُنشئ فيها المشروع
> لا تحتوي على Flutter SDK، لذلك الكود لم يُجمَّع ولم يُختبر.
> قبل أي استخدام فعلي: `flutter pub get` ثم `flutter analyze` ثم `flutter test`،
> ثم تشغيل على جهاز حقيقي.
>
> منطق المزامنة على السيرفر — وهو الجزء الذي لا يجوز أن يخطئ — **مُختبَر بالكامل**
> في `erp/api/tests/Feature/Domain/OfflineSyncTest.php`.

## قواعد العمل دون اتصال

1. الجهاز يرسل **عمليات** لا **نتائج**. السيرفر هو الوحيد الذي يُرحّل.
2. لكل عملية `UUID` و`Idempotency-Key`. إعادة الإرسال بعد انقطاع الرد تُعيد
   الإيصال الأصلي ولا تُنشئ مستندًا ثانيًا.
3. البيع الأوفلاين مقيد بـ:
   - **مخزون السيارة**: مخصص حصريًا لهذا المندوب، لا يستطيع جهاز آخر إنفاقه.
   - **حصة ائتمان محجوزة**: تُحتسب في التعرض المركزي وتختفي عن باقي القنوات.
   - **تفويض محدد المدة والقيمة** (`offline_grants`).
4. الأرصدة المشتركة غير المخصصة تسمح بـ **طلب مبدئي** فقط حتى يؤكده السيرفر.
5. لا يُستخدم «آخر تعديل يفوز» في المال أو المخزون. التعارض يُعرض للمراجعة
   البشرية مع حفظ العملية الأصلية كما أرسلها الجهاز.
6. الرقم الميداني (`field_no`) ليس الرقم المركزي ولا المستند الضريبي.
